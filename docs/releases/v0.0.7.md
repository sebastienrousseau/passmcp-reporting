## Highlights ⭐️

* **Built with Go 1.26.9**: the minimum toolchain moves from 1.26.8, whose standard library carries advisories the processor reaches (GO-2026-6603 to GO-2026-6617); the processor image builds on Go 1.27.2.
* **The processor verifies sha512 subjects**: it now links this module's v0.0.6 verifier, so an attestation whose subject digest is sha512 is accepted instead of refused.
* **Simpler policy and apidoc code**: `Policy.Evaluate` and `scripts/apidoc`'s `check` are split to within the complexity ceilings, with every decision and report unchanged (#13, #14).
* **In lockstep with passmcp 0.0.7**, the family's seventh release. The 0.0.6 changes now sit under their own heading, which the 0.0.6 release run needed and did not find.
