## Highlights ⭐️

* **The processor requires passmcp-reporting 0.0.7**: a release cannot require itself, so 0.0.7 shipped the agentgateway processor against the 0.0.6 verifier (ADR 0002). It now requires the newest release, as every other family member does.
* **Attestations are checked exactly as before**: the verifier packages are unchanged from 0.0.6 to 0.0.8, and a build from the tree was never affected, because `go.work` uses the checkout.
* **In lockstep with passmcp 0.0.8**, the family's eighth release.
