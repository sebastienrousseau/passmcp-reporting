## Highlights ⭐️

* **Processor moved to verifier 0.0.9**: `integrations/agentgateway-extmcp/go.mod` upgrades its `satellion.com/passmcp-reporting` dependency from `v0.0.8` to `v0.0.9` per ADR 0002.
* **15-repository lockstep family table**: `README.md` lists all six Apache-2.0 MCP language SDKs (`passmcp-sdk-go`, `passmcp-sdk-python`, `passmcp-sdk-java`, `passmcp-sdk-cpp`, `passmcp-sdk-typescript`, and `passmcp-sdk-rust`) joining the `0.0.10` release stream.
* **Stable zero-dependency verifier**: `attestation`, `a2a`, `graph`, and `spec` verify statements identically to `0.0.9`, tagged first so `passmcp` `0.0.10` and `passmcp-sdk-go` `0.0.10` can require it.
