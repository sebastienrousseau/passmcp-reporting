## Highlights ⭐️

* **Accepts sha512 subject digests**: the processor links the v0.0.6 verifier, so a valid attestation that names its server by sha512 is no longer refused.
* **Built on patched toolchains**: the module requires Go 1.26.9 and the image builds on Go 1.27.2, both free of the standard-library advisories the processor reached before.
* **Install or run it**: `go install satellion.com/passmcp-reporting/integrations/agentgateway-extmcp/cmd/agentgateway-extmcp@v0.0.7`, or the multi-arch image `ghcr.io/sebastienrousseau/passmcp-agentgateway-extmcp:0.0.7`, published with SLSA build provenance. There was no 0.0.6 processor release.
