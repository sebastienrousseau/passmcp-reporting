## Highlights ⭐️

* **Requires passmcp-reporting 0.0.7**: the processor's `go.mod` moves from the 0.0.6 verifier to the newest release (ADR 0002). Attestations are checked exactly as before, since the verifier packages did not change between the two.
* **Install or run it**: `go install satellion.com/passmcp-reporting/integrations/agentgateway-extmcp/cmd/agentgateway-extmcp@v0.0.8`, or the multi-arch image `ghcr.io/sebastienrousseau/passmcp-agentgateway-extmcp:0.0.8`, published with SLSA build provenance.
